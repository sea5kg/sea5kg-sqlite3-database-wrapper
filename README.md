# sea5kg-sqlite3-database-wrapper

C++ Class-helper for build SQL queries

## How to integrate to your project

via wsjcpp:
```
$ wsjcpp install https://github.com/sea5kg/sea5kg-sqlite3-database-wrapper:master
```

or include this files:

- `src/sea5kg_sqlite3_database_wrapper.h`
- `src/sea5kg_sqlite3_database_wrapper.cpp`

## How use this

Example main func:
```cpp
#include <iostream>
#include <sea5kg_sqlite3_database_wrapper.h>

int main(int argc, const char* argv[]) {

}
```
